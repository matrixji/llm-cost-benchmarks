# llm-cost-benchmarks

This repository contains benchmarks for the cost of using large language models (LLMs) in various applications. The benchmarks are designed to help developers and researchers understand the cost implications of using LLMs in their projects.

## Benchmarks

| --- | --- | --- | --- |

| case1 | Github Copilot (GPT 5.5 7.5x) | 0.93$ |  |
| case1 | Qoder (Auto mode) | 0.16$ | 16 Credits, 0.01$ per credit |
| case1 | Open Code + Qwen 3.6 plus | 0.13$ | 404k input, 7367 output |
| case1 | Claude Code + Qwen 3.6 plus | 0.15$ | 497k input, 5671 output |
